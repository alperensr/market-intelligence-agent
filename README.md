# Market Intelligence Agent

A minimal Node.js and TypeScript project foundation.

## Requirements

- Node.js 24
- npm 11

## Setup

```bash
npm install
```

## Scripts

Run the TypeScript entry point in development:

```bash
npm run dev
```

Check TypeScript types without generating output files:

```bash
npm run typecheck
```

## Project structure

```text
src/index.ts   TypeScript entry point
tsconfig.json TypeScript configuration
.env.example  Secret-free environment-variable template
.gitignore    Files intentionally excluded from Git
```
